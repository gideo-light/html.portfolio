# Threeell Studio

Threeell Studio is a premium managed web studio focused on designing, building, launching, and maintaining high-quality digital experiences.

## Studio Model
We do not simply hand clients a website and disappear. Our standard service combines:
- Strategy and discovery
- Bespoke design
- Development
- Responsive implementation
- Performance and accessibility
- Launch and deployment
- Ongoing maintenance and content updates
- Larger feature work quoted separately

## Repository Purpose
This repository is the studio foundation and portfolio hub. It stores:
- Studio operating standards
- Service architecture
- Client workflow
- Project conventions
- Maintenance rules
- Portfolio planning

Individual client and showcase websites should use separate repositories.

## Core Principle
Choose technology based on the problem, not habit.

WordPress, headless CMS, static/custom frontend, React/Next.js, GSAP, WebGL, or commerce tools are selected only when they improve the project.

## Premium Standard
A Threeell Studio site must be:
- Visually distinctive
- Responsive across desktop, tablet, and mobile
- Fast enough for real users
- Stable across modern browsers
- Accessible at a practical professional baseline
- Easy to maintain
- Documented well enough to revisit months later

See the `docs/` directory for the studio operating system.
