# Design System

## Brand Character
Quiet confidence, physical transformation, editorial restraint.

## Palette
- Ink: #0a0a09
- Bone: #efe7d7
- Ember: #b84f32
- Herb: #5b6742
- Wine: #5e314f
- Charred supporting neutrals

## Typography
Prototype uses a system grotesk stack for utility text and Georgia/Times as an intentionally dependency-free editorial serif.

Before final portfolio publication, evaluate a properly licensed webfont pairing.

## Motion
The experience uses three tiers:
1. utility/UI feedback
2. brand motion
3. spectacle

Tier 3 can be reduced or removed without breaking the page.

## Responsive Principle
Mobile is not a shrunken desktop composition.
- fewer hero cards
- shorter visual density
- no desktop hero pin
- bounded sticky menu visual
- simplified composition where needed

## Accessibility
- visible focus treatment
- semantic headings
- real links/buttons/form controls
- reduced-motion mode
- animation does not carry essential information
