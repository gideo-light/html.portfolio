# Service Architecture

## 1. Managed Website
Best for professional businesses that need an excellent website without complex product functionality.

Typical scope:
- Bespoke visual direction
- Responsive frontend
- Standard page structure
- Contact or enquiry forms
- Analytics
- SEO foundations
- Deployment
- Ongoing maintenance
- Small content updates

## 2. Interactive Premium Website
Best for brands where presentation is a meaningful part of the sale.

Possible scope:
- Scroll-linked storytelling
- GSAP animation
- Advanced transitions
- Kinetic typography
- Interactive galleries
- Pointer/touch effects
- SVG animation
- Selective WebGL or Three.js
- Strong mobile adaptation
- Performance optimization

Important: premium does not mean maximum animation. Interaction must remain purposeful.

## 3. Custom Digital Platform
For projects that go beyond a marketing website.

Possible scope:
- User accounts
- Dashboards
- Booking
- Databases
- Portals
- E-commerce
- Business workflows
- Custom APIs

This category requires project-specific technical review before pricing.

## Maintenance vs New Development

### Usually Maintenance
- Text correction
- Phone/email/address update
- Replacing supplied images
- Updating opening hours
- Small copy updates
- Routine dependency/security maintenance
- Fixing defects in existing functionality

### Usually New Development
- New complex page or user flow
- Booking engine
- Commerce capability
- Account/login system
- Major redesign
- New third-party integration
- New animation system
- New dashboard or database workflow

New development is scoped and quoted separately.
