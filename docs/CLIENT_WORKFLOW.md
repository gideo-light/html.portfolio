# Client Workflow

## Stage 1 — Qualification
Determine:
- What the business does
- Why it needs the site
- Required launch timing
- Budget fit
- Required functionality
- Who approves decisions
- Whether the project is a website, premium interactive website, or platform

## Stage 2 — Discovery
Collect:
- Brand assets
- Content
- Existing website
- Competitors
- References
- Audience
- Business goals
- Required integrations
- Required legal/privacy content

## Stage 3 — Scope
Write down:
- Pages
- Features
- Content responsibilities
- Number/type of review rounds
- Launch responsibilities
- Hosting responsibilities
- Maintenance inclusions
- Explicit exclusions

## Stage 4 — Art Direction
Define:
- Visual concept
- Typography
- Color
- Image direction
- Interaction philosophy
- Motion intensity
- Mobile behavior

## Stage 5 — Build
Build from approved direction.

## Stage 6 — QA
Test:
- Desktop
- Tablet
- Mobile
- Touch
- Navigation
- Forms
- Links
- Loading
- Core accessibility
- SEO metadata
- Browser behavior
- Performance
- Error states

## Stage 7 — Client Review
Collect changes in an organized batch where possible.

Separate:
- Defects
- In-scope revisions
- New requests

## Stage 8 — Launch
Confirm:
- Production deployment
- Domain
- SSL
- Forms
- Analytics
- Search metadata
- Backup/rollback
- Client approval

## Stage 9 — Management
Operate under the maintenance agreement.

Every new request should be classified before work starts:
- Routine maintenance
- Included content update
- Billable enhancement
- New project
