# Threeell Studio — Operating System

## Positioning
Threeell Studio designs, builds, launches, and manages premium websites and digital experiences.

The client buys an outcome: a strong digital presence that is professionally maintained. They do not need to understand the implementation stack.

## What We Sell
1. Managed Website
2. Interactive Premium Website
3. Custom Digital Platform

## Revenue Structure
- Initial strategy/design/development fee
- Recurring management fee
- Major changes and new functionality quoted separately

## Studio Rules
- Never promise functionality before confirming technical feasibility.
- Never treat unlimited redesign work as maintenance.
- Never put secrets, API keys, passwords, private keys, or credentials in GitHub.
- Every project must have documented deployment and maintenance instructions.
- Every project must be tested on desktop and mobile before launch.
- Reuse engineering patterns, not identical visual designs.
- Animation must support the experience, not damage usability or performance.
