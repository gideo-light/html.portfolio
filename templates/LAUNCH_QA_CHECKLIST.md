# Launch & QA Checklist

## Content
- [ ] Final approved copy is present
- [ ] No placeholder text remains
- [ ] Contact details verified
- [ ] Business hours/details verified where relevant
- [ ] Images have appropriate rights/approval
- [ ] Favicon and brand assets present

## Responsive
- [ ] Small phone
- [ ] Large phone
- [ ] Tablet portrait
- [ ] Tablet landscape
- [ ] Laptop
- [ ] Large desktop
- [ ] No horizontal overflow
- [ ] Touch targets are usable

## Navigation & Interaction
- [ ] Main navigation works
- [ ] Mobile navigation works
- [ ] All buttons work
- [ ] All links work
- [ ] Hover states have touch-safe alternatives
- [ ] Scroll-linked effects do not block navigation
- [ ] Reduced-motion behavior considered
- [ ] No essential information depends only on animation

## Forms
- [ ] Required fields work
- [ ] Validation works
- [ ] Success state works
- [ ] Failure state works
- [ ] Destination inbox/system verified
- [ ] Spam protection configured where appropriate

## Performance
- [ ] Images optimized
- [ ] Video optimized/lazy-loaded where appropriate
- [ ] Fonts loaded responsibly
- [ ] Heavy animation tested on mobile
- [ ] No obvious layout shift
- [ ] No unnecessary blocking assets

## Accessibility Baseline
- [ ] Semantic headings
- [ ] Useful alt text
- [ ] Keyboard navigation
- [ ] Visible focus states
- [ ] Sufficient text contrast
- [ ] Forms have labels
- [ ] Interactive elements are actual controls/links where appropriate

## SEO & Sharing
- [ ] Page titles
- [ ] Meta descriptions
- [ ] Canonical strategy where needed
- [ ] Open Graph/social image
- [ ] Robots behavior checked
- [ ] Sitemap configured where appropriate
- [ ] Structured data considered where appropriate

## Production
- [ ] Domain points correctly
- [ ] HTTPS works
- [ ] WWW/non-WWW redirect decision implemented
- [ ] Production environment variables configured
- [ ] Analytics works
- [ ] 404 page works
- [ ] Backup/rollback path documented
- [ ] Deployment documented
- [ ] Repository production branch confirmed

## Final
- [ ] Client/studio approval recorded
- [ ] Maintenance classification confirmed
- [ ] Launch date recorded
- [ ] First post-launch check scheduled internally
